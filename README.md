# Калькулятор пассивного дохода из облигаций

Веб-калькулятор, который показывает, какой капитал нужен, чтобы получать заданную сумму пассивного дохода в месяц с облигаций разного риска.

Приложение берёт актуальные цены, купоны и доходности с Московской биржи (MOEX ISS) и считает:

- сколько нужно вложить в выбранную подборку облигаций;
- сколько откладывать каждый месяц с реинвестированием купонов и без него;
- календарь купонных выплат на 12 месяцев;
- график роста капитала на выбранном горизонте.

## Как запустить локально

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

По умолчанию dev-сервер слушает `http://127.0.0.1:43173/passiv-calc/`.

Сайт на GitHub Pages: https://misha222002.github.io/passiv-calc/

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Как пользоваться

1. Выберите или введите цель по пассивному доходу в месяц.
2. Выберите сценарий риска — от ОФЗ до более доходных корпоративных выпусков.
3. Настройте срок накопления и реинвестирование купонов.
4. При необходимости обновите котировки кнопкой «Обновить цены MOEX».

Расчёты носят ознакомительный характер и не являются индивидуальной инвестиционной рекомендацией.
